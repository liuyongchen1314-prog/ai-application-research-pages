# 人工智能全产业链研究系统

这是公开发布版仓库，覆盖 A 股与港股共 142 家人工智能产业链公司。

核心规则：

- 142/142 家公司都必须显示数值化的合理估值范围。
- 合理估值范围与交易入场条件分开，技术走势不能反向抬高合理价值。
- 估值证据尚未完全闭环的公司仍给出低置信度研究区间，但交易行动标记为“暂不参与”。
- 北京时间 16:30 前不把当天盘中数据混入日终复盘。
- 工作日收盘后自动刷新行情、日线、分时、估值位置、趋势、相对强弱、波动收缩和交易行动层。
- 页面以中文为主，不使用长串英文缩写作为可见说明。

## 估值状态

- **已审计估值区间**：前期估值链已完成较高强度审计，可进入后续交易条件筛选。
- **条件估值区间**：已有可用区间，但仍有条件项需要继续验证。
- **低置信度研究区间**：为了保证最终系统 142/142 都有价格范围而保留的数值研究带；不等于正式估值通过，默认暂不参与交易筛选。

## 数据与风险

行情使用公开市场数据源。估值研究后续继续通过公司公告、东方财富、同花顺和机构研报交叉校验。机构目标价仅用于横向检查，不作为反推合理价值的主模型。

本系统用于个人研究与决策辅助，不构成收益承诺。
